# Design: Cala Match (Stitch prototype)

Design demo generated with Google Stitch on 14/11. It is a reference for the app, not the app itself: `app/` (Expo) is built from it.

| Folder | Screen |
|---|---|
| `stitch/feed/` | Feed with the Raising / Investing switch, filter chips and affinity cards |
| `stitch/detail/` | Detail of an investor or startup (Northwind Capital): why you match, key facts, rounds, people, sources |
| `stitch/chat/` | Chat assistant with structured answers |
| `stitch/context/` | Context: PDF, voice note, text note and what the app understood |
| `stitch/profile/` | Profile and settings |
| `stitch/DESIGN.md` | Design system: color tokens, typography, spacing |

Each screen folder has `screen.png` (the picture) and `code.html` (Tailwind, opens in a browser). Names and figures in the mockups are made up.
